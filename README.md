### **Классовый подход и структура проекта**

---

Мы строим проект на классовом подходе: в основе лежит базовый компонент Block, который управляет жизненным циклом и рендерингом, а взаимодействие между модулями идёт через EventBus. Такой подход даёт гибкость и снижает связанность кода.

Структура приложения разделена на понятные папки:

- framework — фундамент (Block, EventBus, HTTPTransport) 🧱
- components — кнопки, поля ввода и прочие кирпичики интерфейса 🧩
- pages — страницы приложения (Login, Chats, Profile и т.д.) 📄
- services — работа с API 💬
- controllers — связь View и сервисов ⚡

Это делает код чище, понятнее и реально ближе к архитектуре MVC.

### **Кодстайл и Чистюли**

---

Наш проект — это не просто мессенджер, а настоящий SPA-спа для кода 🛁.

**Автоматические проверки:**

- За порядком в JavaScript/TypeScript следит строгий ESLint 👮‍♀️
- За стилями зорко присматривает Stylelint 💅
- А Prettier работает как стилист, который даже пробелы укладывает по фен-шую ✨
- Каждый коммит проходит через линтинг, форматирование и проверки типов (tsc --noEmit) — никакой грязи и кривых скобочек в репозитории!

**Pre-commit hooks:**

- 🪝 **Husky** - автоматически запускает проверки перед каждым коммитом
- 📋 **lint-staged** - проверяет только измененные файлы для скорости
- 🧪 **Автоматические тесты** - запуск связанных тестов при изменении кода
- 🚫 **Блокировка коммитов** - коммит не пройдет, если есть ошибки линтинга или тестов

**Качество кода:**

- У нас всё по кодстайлу: кавычки ровные, пробелы нежные, отступы как по линейке 📏
- Каждый компонент покрыт тестами для надежности 🧪
- Строгая типизация TypeScript предотвращает ошибки во время разработки 🎯

Итог: наш код не только работает, но и выглядит так, что на него приятно смотреть 👀❤️.

### **Роутинг: супер навигация**

---

Теперь есть роутинг!

**Что умеет наш роутер:**

- 🏠 `/` — страница входа (добро пожаловать домой!)
- 📝 `/sign-up` — регистрация новых друзей
- ⚙️ `/settings` — настройки профиля (как настроить себя под себя)
- 💬 `/messenger` — главная сцена общения

**Суперспособности роутера:**

- 🎯 Только одна страница активна в DOM (никаких дублей!)
- 🔄 При обновлении страницы URL остается верным (как GPS-навигатор)
- ⬅️➡️ Кнопки "Назад" и "Вперед" браузера работают как часы
- 🛡️ Проверка авторизации — неавторизованных разворачиваем
- 🚀 Авторизованных пользователей сразу ведем в мессенджер

Роутер построен на паттерне Singleton и использует History API — никаких хешей, только чистые URL! ✨

### **API: Разговор с сервером на одном языке 🌐**

---

Наш мессенджер умеет говорить с сервером на всех языках HTTP! Мы реализовали полный набор API для комфортного общения.

**Авторизация и пользователи 🔐:**

- 📝 Регистрация новых пользователей
- 🚪 Вход в систему (добро пожаловать!)
- 👋 Выход из системы (Пока пока!)
- ✏️ Изменение данных профиля
- 🖼️ Загрузка и смена аватара
- 🔒 Смена пароля (безопасность превыше всего!)

**Чаты и сообщения 💬:**

- 📋 Получение списка чатов пользователя
- ➕ Создание новых чатов
- 👥 Добавление пользователей в чат
- ❌ Удаление пользователей из чата
- 📊 Получение списка участников чата
- 🎫 Получение токенов для WebSocket

**Real-time общение через WebSocket ⚡:**

- 🔌 Подключение к чату через WebSocket
- 📨 Отправка сообщений в реальном времени
- 📜 Загрузка истории сообщений
- 🔄 Автоматическое переподключение при сбоях

Все API построены на HTTPTransport с поддержкой типизации TypeScript — никаких сюрпризов, только предсказуемые ответы! 🎯
