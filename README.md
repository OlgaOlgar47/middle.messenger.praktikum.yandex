### **Классовый подход и структура проекта**

---

Мы строим проект на классовом подходе: в основе лежит базовый компонент Block, который управляет жизненным циклом и рендерингом, а взаимодействие между модулями идёт через EventBus. Такой подход даёт гибкость и снижает связанность кода.

Структура приложения разделена на понятные папки:

- framework — фундамент (Block, EventBus, HTTPTransport) 🧱
- components — кнопки, поля ввода и прочие кирпичики интерфейса 🧩
- pages — страницы приложения (Login, Chats, Profile и т.д.) 📄
- services — работа с API 💬
- controllers — связь View и сервисов ⚡

Это делает код чище, понятнее и реально ближе к архитектуре MVC.

### **Кодстайл и Чистюли**

---

Наш проект — это не просто мессенджер, а настоящий SPA-спа для кода 🛁.

- За порядком в JavaScript/TypeScript следит строгий ESLint 👮‍♀️
- За стилями зорко присматривает Stylelint 💅
- А Prettier работает как стилист, который даже пробелы укладывает по фен-шую ✨
- Каждый коммит проходит через линтинг, форматинг и проверки типов (tsc --noEmit) — никакой грязи и кривых скобочек в репозитории!

У нас всё по кодстайлу: кавычки ровные, пробелы нежные, отступы как по линейке 📏.

Итог: наш код не только работает, но и выглядит так, что на него приятно смотреть 👀❤️.
